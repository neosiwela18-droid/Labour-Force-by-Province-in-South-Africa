# Labour Force by Province in South Africa

In this project, I use Python, pandas, and Matplotlib to analyse and visualise labour-force data for South Africa’s provinces. I load the CSV file into a pandas DataFrame, then select the `placeName` column for the province names and the `Value:Count_Person_InLaborForce` column for the labour-force figures. I create a bar chart to compare the number of people in the labour force across provinces. To make the large values easier to read, I use `FuncFormatter` to display the y-axis in millions, such as `7.2M` instead of `7,200,000`. Finally, I add a title, bold axis labels, and horizontal grid lines before displaying the chart.
